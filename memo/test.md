14:intern()とコンスタントプールについて

配列の操作について
配列の定義は
int[] 変数名;というように定義可能
この時点では変数の中に配列本体は宣言されていない。
int[] nums = new int[3];
これで要素数３の配列を作成できる。
中身は自動的に初期化されるため実質[0,0,0]となっている。

別の定義方法として
int[] nums = {10,20,30}というようにもできる
int[] nums = new int[]{10, 20, 30};
これも可能。
だけど
int[] nums = new int[3]{10, 20, 30};
これはダメ、要素数の定義方法を２つ利用するのはコンパイルエラーになります。

宣言と代入を分けることも可能
int[] nums;

nums = new int[]{10, 20, 30};

しかし！！！！
int[] nums;

nums = {10, 20, 30};
これはコンパイルエラーになる。
りゆうとしては{10,20,30}で定義できるときは宣言と同時に初期化するときと決まっているから
