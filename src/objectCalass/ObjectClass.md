クラス定義とオブジェクトについて

集合体データ型を表す物をクラスという。
属性：変数。データにあたるもの
操作：メソッド。属性を処理するもの

クラスはこの二つの要素をつかさどる
クラスの中のメソッド及び変数をメンバという

オブジェクトとは
クラスをデータに展開し、実体化するインスタンス化を行うそこでの生成物がオブジェクト。
オブジェクトはクラスを展開したもの実体。

クラス定義
構文
[修飾子]class クラス名{}
class Employee {}←これは修飾子がない。それでも問題ないです。

変数定義
構文
[修飾子] データ型 インスタンス変数名

class Employee{
String name;
int id = 100;
}

メソッド定義
社員のIdを取得したり、踏力したりする処理のことをメソッドという
構文
int id;
void setId (int i ){
i = 1
}
setId(100)でidを100として登録できる

int getId(int i){
return id;
}
これでIdを取得し返ってくる。

構文
[修飾子] 戻り値の型 メソッド名(引数){
処理文
}
修飾子はprivateやpublicなどに使われる

インスタンス化について
クラスをもとに新しいデータ（オブジェクト）を作成することをインスタンス化という。インスタンス化するにはnewキーワードを使用する

構文
データ型 変数名 ＝ new クラス名();
Employee a = new Employee();

呼び出し方は
a.setId(100)このようにメソッド名とインスタンス化した際の変数名で呼び出せる

メンバ変数とローカル変数
メンバ変数はそのクラスで使用できる変数のこと、クラス内であれば誰でも参照可能。
ローカル変数はメンバクラス内でメソッドやブロックが生成された際にその中で定義しているもの。領域外からは参照できず、明示的に初期化を行う必要がある。

コンストラクタについて
コンストラクタとはクラスに定義するものであり、インスタンス化の際に最初にブロックに呼び出すもの、
基本的にはメソッドと定義方法は似ているが以下のルールがある。

名前がクラス名と同じ
戻り値は持たない（戻り値も定義しない）
必要に応じて引数を受け取ることができる
構文
[修飾子] コンストラクタ名(引数リスト){
}

class Employee{
int id;

コンストラクタの定義
Employee(int i){
id=1;
}
}

コンストラクタの呼び出し
Employee　e = new Employee();
Employee　e = new Employee(100);←このようにするとsetIdを呼ぶ工程を省略できる。
コンストラクタはオブジェクトを生成することで呼び出され、初期化もできる特殊なもの

デフォルトコントラクタ
コンストラクタを定義しない場合、コンパイラによって自動でコンストラクタにする。
特徴は引数を持たない。実装は空というもの。

デフォルトコンストラクタはクラスに一つもコンストラクタを定義しなかった時に追加される。


オーバーロードとは
同じ名前のメソッドやコンストラクタを複数定義できる。
その場合、引数の並びｍデータ型、数が異なっていることが条件。メソッドも名は同じであるため、引数をもとにして呼び出されるメソッドとコンストラクタが決定される。
つまり、引数と型や数、並びから判断して目的のメソッドを指定できる。


カプセル化
ほかのメソッドやクラスからのアクセスを制限する考え方。
インスタンス変数はprivate、メソッドはpublicが推奨されている。
外部からの直接的な指定を拒否できるためデータの保護ができる。
publicクラスは1つのファイルにつき一つしか記述できない。
そして定義した場合、そのソースファイルの名前は指定したクラスメイト同じでなくてはならない。


値コピーと参照情報のコピー
引数・戻り値における基本データ型と参照型の違い
メソッドの引数に値を渡したとき、その値が基本データ型(intやLong)の場合は、その値をコピーし処理を行う。
しかし、参照型(Stringや配列やList、enum)などこれらは参照している元のデータを改変する。つまり呼び出し元の値も変わる

ガベージコレクタ
プログラムが使用しなくなったメモリ領域を検出し、解放する。
参照している先のインスタンスがなくなるまたは機能を失ったときにそこを解放する。
必要に応じてそこをガベージコレクタの対象にすることが可能。

1　nullを代入
個の変数はオブジェクトを参照しないということを明示的にnullにする。
