継承とポリモフィズム
既存のクラスをもとに新しいクラスを定義することができる。これを継承という。
元なるクラスをスーパークラスといい、新たに定義されているクラスをサブクラスという

構文
[修飾子] class サブクラス名 extends スーパークラス名{}
class Employee{}
class Sales extends Employee{}

スーパークラスの中にある変数やメソッドはサブクラスに引き継がれる。
スーパークラスはサブクラスに一つしか継承できない。


オーバーライド
スーパークラスのメソッドと同じ名前でメソッドを定義することができる。
サブクラスがインスタンス化され。オーバーライドされたメソッドが呼び出された場合は、オーバーライドされたものが優先的に呼び出される。

ルールとして
メソッド名、引数名が同じであること、戻り値はスーパークラスで定義したメソッドが返す型と同じか、そのサブクラス型でないといけない。
また、アクセス修飾子はスーパークラスと同じか、それよりも範囲が広いものでないといけない。
サブクラスのみ処理を変更したいときに有効。　　


thisとsuperの利用
thisは自分自身のオブジェクトを表現する
int id;インスタンス変数
void setId (int id){ローカル変数
id=id;
}
このようになっているときにローカル変数とインスタンス変数の名前が同じ場合、インスタンス変数への代入は行われない。
だからthisを付ける
