演算子について

●算術演算子と単項演算子
これらは加減乗除を使用する。
+ - * / % ++ --
これらを使用するよ
間違えやすいのは/ %のところかな。普通の割り算は「/」これ、「%」は**余り**を出す

●インクリメント、デクリメント（単項演算子）
[++]と[--]これのコト
つける位置で処理の順番が違う。
int a = 10;
int b = ++a;
この場合、計算してから代入する。つまり変数aの値は変化してしまう。

int a = 10;
int b = a++;
この場合は、代入してから計算する。変数aは変化しない。


●論理演算子
& | ^ ! これらの記号を使ったものがある。

and条件（二つの条件がtrueであればtrueを変えす）
[&]または[&&]
条件１ & 条件２　
この場合は条件1がfalseだとしてもすべて評価する。

条件１　&& 条件2
この場合は条件1がfalseの時点で評価終了。


or条件（どちらががtrueであればtrueを返す）
条件1 | 条件2
同じくfalseであっても評価する。

条件1　||　条件２
条件1がtrueなら条件2は見ない


switch文　条件分岐の表現の一つ
switch(式){
case 定数1：式の結果が定数１と一致したときに処理が実行
処理１；

case2 定数2：式の結果が定数２と一致
処理2;

default:上記のどのcaseにも一致しなかった時処理
}
文の式の結果はchar byte short int 及びそのラッパークラス、enum Stringのいずれかが必要であり、それ以外はコンパイルエラー。
また、条件式の値がnullであると、実行時にNullPointerExceptionが発生する。
