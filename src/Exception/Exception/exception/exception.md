例外処理について
そもそも例外とは

コンパイルが成功していても実行した際にエラーになることがある。それを例外という。
例外が発生することを例外がスローされるという。

例外クラス
checked例外とunchecked例外
例外クラスはこれら2種類に分けられる。
checked例外(定義は必須) はプロジェクト外が原因のエラー、unchecked(定義は必須でない)は実行中のプログラムが原因で発生する例外

ルールとして、
Errorクラスは必須でないが、メモリ不足などの実行環境で発生する致命ていきなエラーをキャッチする。
Exceptionクラスはアプリケーション内の物。これは必須でない場合と必須である場合があり、それは例外の可能性がある場合に例外クラスが何かというところで判断する。

独自例外
自分で作成することも可能。
構文
[修飾子] class クラス名 extends Exception{ }
public class MyException extends Exception{ }
