
##変数について

●リテラル
Javaの言語はリテラルといわれる。そしてそれらは6種類ある。

①整数リテラル
小数点がないもの、10進数、２進数、８進数、１６進数

②浮動小数点数リテラル
１０進数、進数を表現する
10進数　12.33　指数：3e4　3*10 4乗ということ

③文字リテラルとUnicode
1文字　'A' シングルクォート
Unicode'￥u3012'　￥uの後に4桁の１６進数を指定するとunicodeになる
Linux環境下だとASC文字コード、WindowsだとJISになる。JISは￥になるけどASCIIだと\になる。

④文字列リテラル
定義には“”が必要。

⑤論理値リテラル
trueかfalseで表現する

⑥nullリテラル
何も参照していないという状態の


●変数
変数はプログラムを実行するための入れ物。クラスやメソッドなどをつけるときの名前は識別子という！

●データ型
変数を定義するとき、どのような値を格納するのかをデータ型で指定する。
基本データ型と参照型がある。

変数宣言
データ型　変数名;
変数名 = 値;
宣言する変数を使い始める前に値を入れることを変数の初期化という。

●ローカル変数の型推論
ローカル変数を宣言する場合、通常とは別の定義ができる。
int num = 10;
var num  = 10;
メソッドの引数やコンストラクタの引数、戻り値などには宣言できる。
