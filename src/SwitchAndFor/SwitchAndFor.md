繰り返しと制御文

構文
while(条件式){
処理分 ←条件式がtrueの時のみ実行される
}
条件式にfalseが入るとコンパイルエラーになる。条件式にtrueを入れると無限ループにすることができる。

do-while文
do{
処理文
}while(条件文);
条件判定式がfalseになった時点で処理を修了するということ。最初がどうであれ実行する。

for文と拡張for文
構文
for(式1; 式2; 式3;){
処理分
}
式1で変数の初期化を行う。これをカウンタ変数という。この初期化を行うのは処理の中でも一回だけ。
式の2にはbooleanになる条件文を作成する必要がある。これがfalseになったら処理が終了
式3にはカウンタ変数を更新する方法を書く

式1の時に宣言する型は一回のみ宣言可能。
for(int i1 = 0,i2 = 0 ; i1 + i2 <5; i4++){
これでも動きます


拡張For文
配列やコレクションの全要素を順番に取り出し、処理する場合に使われるもの。

構文
for(変数:参照変数名){
処理文
}
処理文内で代入されるため、参照変数の型に合わせる必要がある。


制御文のネスト
制御文の中に入れ子も可能。
forやwhileの中に制御文を入れるときはネストの深さに気を付けよう


繰り返し制御文
条件式が繰り返される中、ある特定の値が入ってきたときに繰り返し処理から抜けたいとする。そんなときの物。

break文
実行中の繰り返し文を中断し、処理を抜け出すもの。

continue文
その処理をスキップし、次の処理に進む

ラベル
繰り返し文がネストしている場合、内側の文章に書いたbreakやcontinue文は内側の文章のみ適応される。
外側からも抜けたい場合はラベルを使用する。つまり2重のFor文などからも抜けたいときに使う。
